# 🏦 FinPulse — NatWest Segment Risk Intelligence

## i. Overview

FinPulse is a bank-grade AI risk intelligence system built for NatWest's retail banking operations. Instead of forecasting a single customer's balance, FinPulse forecasts the **Financial Health Score (FHS)** of 1,000 customers across 8 Indian banking segments, predicting population-level financial distress 12 days before it occurs. The system enables NatWest's relationship managers to take proactive action — offering micro-loans, restructured EMIs, or financial wellness outreach — before customers default.

**Problem solved:** NatWest relationship teams currently react to defaults after they happen. FinPulse shifts this to predictive, proactive intervention.

**Intended users:** NatWest retail risk managers and relationship teams.

---

## ii. Features

- **Risk Heatmap:** Real-time FHS dashboard showing all 8 customer segments colored RED / YELLOW / GREEN based on their financial health score
- **30-Day FHS Forecast:** AI-powered forecast using Holt-Winters Exponential Smoothing with uncertainty bands (yhat, yhat_lower, yhat_upper)
- **Baseline Comparison:** 30-day Simple Moving Average plotted alongside the AI forecast to demonstrate model value over naive prediction
- **Anomaly Detection:** Automatic flagging of segments where the worst-case lower bound drops below critical thresholds within 14 days
- **Scenario Testing:** Interactive slider to simulate expense shocks (0–50%) across all segments and instantly observe FHS impact
- **AI Intervention Recommendations:** Gemini API integration generating 1-2 sentence actionable recommendations per flagged segment
- **Synthetic Data Generation:** Realistic 2-year daily balance data for 1,000 customers with salary cycles, rent, groceries, and random shock events

> **Note on LLM integration:** The Gemini API (gemini-2.0-flash-lite) is fully integrated with live API calls attempted on each run. Due to Google's free-tier rate limits on unverified projects, curated fallback responses are used for demo stability. The API call architecture is live and will work with a billing-linked project.

## iii. Install and Run Instructions

**Prerequisites:** Python 3.10+, Git

### 1. Clone the repository
```bash
git clone https://github.com/M3hul-raj/FinPulse-NatWest.git
cd FinPulse-NatWest
```

### 2. Create and activate virtual environment
```bash
python -m venv venv

# Windows
venv\Scripts\activate

# Mac/Linux
source venv/bin/activate
```

### 3. Install dependencies
```bash
pip install -r requirements.txt
```

### 4. Set up environment variables
```bash
# Windows
copy .env.example .env

# Mac/Linux
cp .env.example .env
```

Edit `.env` and add your Gemini API key:
```
GEMINI_API_KEY=your_key_here
```
Get a free key at: https://aistudio.google.com/app/apikey

### 5. Generate synthetic data (first time only)
```bash
python src/customer_generator.py
```
This generates `data/historical.csv` with 730,000 rows. Takes ~30 seconds.

### 6. Run the app
```bash
streamlit run src/app.py
```
Dashboard opens at http://localhost:8501. First load takes 5-8 minutes (calculating 90,000 FHS statistical data points across 8 segments). Subsequent loads are cached.

### 7. Run tests
```bash
pytest tests/test_forecaster.py -v
```
Expected: 12 passed.

## v. Usage Examples

### Main Dashboard
After running `streamlit run src/app.py`:
1. View the **Risk Heatmap** — 8 segment boxes showing current FHS and risk level
2. Select any segment from the dropdown to see its **30-day forecast chart**
3. Read forecast metrics: Day 1 FHS, Day 30 FHS, worst-case lower bound, best-case upper bound
4. Scroll to **Early Warning Alerts** — segments flagged for intervention with severity level
5. Expand any alert to see AI-generated intervention recommendation

### Scenario Testing
Use the sidebar slider **"Simulate expense shock (%)"** to model events:
- 10% shock → mild inflation impact
- 30% shock → housing cost spike
- 50% shock → economic crisis scenario

The heatmap and forecasts update instantly to reflect the simulated scenario.

## vi. Architecture

```
User (Browser)
     │
     ▼
Streamlit UI (src/app.py)
     │
     ├──► Customer Data (data/historical.csv)
     │         └── Generated by src/customer_generator.py
     │              └── 1,000 customers × 8 segments × 730 days
     │
     ├──► FHS Calculator (src/fhs_calculator.py)
     │         └── FHS = 0.4×Trend + 0.3×Regularity + 0.2×Volatility + 0.1×Debt
     │
     ├──► Forecaster (src/forecaster.py)
     │         └── Holt-Winters → yhat / yhat_lower / yhat_upper (30 days)
     │
     ├──► Anomaly Detector (src/anomaly.py)
     │         └── Flags segments below critical FHS threshold (next 14 days)
     │
     └──► LLM Explainer (src/llm_explainer.py)
               └── Gemini API → 1-2 sentence intervention recommendation
```

**FHS Formula:**
```
FHS = (0.4 × Balance Trend) + (0.3 × Income Regularity)
    + (0.2 × Spending Volatility) + (0.1 × Debt Ratio)

Score: 0–100 | <60 = RED | 60–75 = YELLOW | >75 = GREEN
```

## vii. Limitations

- Synthetic data only — no real NatWest customer data used
- LLM recommendations use curated fallback responses due to Gemini free-tier rate limits on unverified Google Cloud projects; live API calls are attempted first on every run
- Forecast accuracy depends on synthetic data patterns; real-world performance would require historical transaction data
- FHS weights (0.4, 0.3, 0.2, 0.1) are heuristic — production deployment would use ML-optimized weights trained on historical default data
